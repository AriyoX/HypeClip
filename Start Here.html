Start using HypeClip

Use a Windows x64 PC with internet access for the first setup. Models and tools can take several GB.

Open HypeClip

  • Installer — Open the HypeClip Setup file and choose Install. Use HypeClip in the Windows Start menu to open it again.
  • ZIP — Right-click the ZIP and choose Extract All. Open the extracted HypeClip folder and double-click Start HypeClip.cmd. Windows may show the name as Start HypeClip.

Set up tools and models

  1. Accept the Node.js install if the launcher asks. HypeClip opens in your browser.
  2. If you land on Setup, choose Install tools and models. Approve the Windows installer prompts and wait for the tools to show Ready.
  3. Choose Continue to Monitor. You can make and save clips without an account or API key.

Make your first clip

  1. In Monitor, choose Choose a stream, then Local recording. Browse for a video you have permission to edit.
  2. Choose Check source, confirm your permission, then choose Monitor once. HypeClip scans the recording for a highlight.
  3. Open Clips to watch the result. Choose Open folder to find the saved MP4 or Download MP4 to take a copy.

Save and share clips

Clips go to Videos\HypeClip\Studio by default. To pick another drive or folder, open Settings → Clips folder, choose Browse, then Save folder.

To post yourself, upload the saved MP4 in TikTok. Use Publishing → Schedule with Buffer for automatic posting. That option uses R2 to give Buffer a public link to the finished MP4. Buffer’s media requirements

Run again or get unstuck

  • Keep the HypeClip window open and the PC awake while a source is running. If you close the browser tab, open HypeClip again.
  • For live links, install Streamlink in Setup. Add Twitch or YouTube credentials there if you want to collect chat on those services.
  • If you see an App Installer or WinGet error, install or update App Installer in the Microsoft Store and try again.
  • The Windows installer is unsigned. If Windows blocks it, use the ZIP version.
